# rs_calc
> a small caculator made using rust

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)]()

---

## features

- **Parse arguements:** parse some arguement from command
- **BigDecimal:** accurate calculate to solve the classic problem 0.1 + 0.2 != 0.3
- **REPL:** a way to calculate

---

## Prerequisites

before running this project please install those depandencies

- rustc >= 1.99.1
- bigdecimal >= 0.4.11

---

## Quick Start

### 1. clone project
``` bash
git clone https://github.com/Jim-2330/rs_calc.git
cd rs_calc
```

### 2. add depandencies
``` bash
cargo add bigdecimal
```

### 3. install it
``` bash
cargo install --path . --force
```

---

## demo to use
``` bash
rs_calc -h
```
